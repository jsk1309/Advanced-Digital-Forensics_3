# Every Wire Leaves a Trace
## Advanced Digital Forensics & Internship at United Telecom Ventures

### 📌 Overview
This repository documents my internship experience at **United Telecom Ventures, Mumbai**, as a Technical Intern in ELV Systems & Project Support.

**Internship Duration:** July 2026 – Ongoing  
**Role:** Technical Intern – ELV Systems & Project Support  
**Domain:** CCTV, Access Control, Networking and ELV Security Systems

The internship focused on ELV system design, CCTV surveillance concepts, BOQ preparation, system architecture, technical comparisons, project tracking and procurement documentation.

The central theme of this internship was understanding how security and communication systems generate digital traces that can become valuable sources of evidence during forensic investigations.

### 🔍 Connection with Advanced Digital Forensics

My internship activities were mapped to five key areas of Advanced Digital Forensics.

#### 1. Digital Evidence Acquisition
- Studied NVRs and CCTV storage systems while preparing surveillance designs.
- Explored native-format video export and audit logs.
- Understood NTP time synchronisation and export-only user roles.
- Studied forensic imaging, write blockers and SHA-256 hash verification.

#### 2. File System and Data Recovery
- Studied CCTV storage sizing and NVR circular overwriting.
- Explored file carving and deleted footage recovery concepts.
- Cleaned large rate-card databases through segregation, duplicate removal, missing-field recovery and data validation.
- Practised maintaining original data by working on copies.

#### 3. Digital Forensic Investigation Tools

Explored the applications of:

- **FTK Imager:** Forensic disk imaging and hash verification.
- **Autopsy:** File analysis, timelines and keyword searching.
- **Wireshark:** Network traffic analysis.
- **Email Header Analysis:** Understanding email authenticity and spoofing.
- **ExifTool:** Examining image metadata.
- **Hashing Utilities:** Verifying digital file integrity.

#### 4. Network and Email Forensics
- Studied IP camera networks using PoE switches and fibre backbones.
- Explored switch logs, firewall logs, DHCP leases and NVR audit logs.
- Studied IP-PBX Call Detail Records as potential evidence sources.
- Explored email header analysis, SPF, DKIM and DMARC.
- Understood how suspicious vendor payment-change requests can indicate email spoofing.

#### 5. Mobile and Cloud Forensics
- Studied digital traces generated by mobile CCTV viewing applications.
- Explored mobile access-control credentials and timestamped events.
- Understood EXIF metadata in site photographs, including location and time information.
- Studied cloud-stored project documents, version histories and access logs.

### 🧪 Mock Forensic Investigation

**Case Study: Gate 2 at 02:14**

A simulated investigation was developed around a hypothetical incident at a perimeter CCTV site.

The investigation followed the I-P-C-A-R approach:

1. **Identify:** Identify relevant CCTV footage and system logs.
2. **Preserve:** Export evidence copies, calculate SHA-256 hashes and document custody.
3. **Correlate:** Compare CCTV, access control and network timestamps.
4. **Analyse:** Build a combined incident timeline.
5. **Report:** Document findings, evidence references and chain of custody.

*This is a hypothetical academic case study, not an actual investigation.*
